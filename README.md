# PR1
This Python program demonstrates how to take user input and work with basic Python data types. It collects the user's name, age, height, and favorite number, then displays their types and object IDs.
 display types with print("name:", name, "Type:", type(name)) function.
 display IDs with print("name:", name, "id:", id(name)) function.

Features:
Takes user input using input()
Demonstrates Python string data types
Displays the type and ID of variables
Uses the datetime module
Calculates the approximate birth year
Displays the current year and today's date
Technologies Used:
Python
datetime module 
my datetime module is datetime.date.today().year
